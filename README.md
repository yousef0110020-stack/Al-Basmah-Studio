# Al Basmah AI Media Studio — استوديو البصمة للوسائط (MVP 0.1)

نظام فعلي لمعالجة صور وفيديوهات العقارات لشركة البصمة للعقارات: خادم **FastAPI** + محركات **FFmpeg / OpenCV / Pillow** + واجهة ويب فاخرة (أسود وذهبي) بالعربية والإنجليزية تعمل على الكمبيوتر والآيفون عبر المتصفح.
كل الأدوات مفتوحة المصدر ومجانية. لا يستخدم النظام أي خدمة مدفوعة أو اتصال خارجي.

## التشغيل

المتطلبات: Python 3.10+ و FFmpeg (مع vid.stab — موجود في نسخ FFmpeg الرسمية).

```bash
# macOS:   brew install ffmpeg python
# Windows: winget install Gyan.FFmpeg Python.Python.3.12
# Ubuntu:  sudo apt install ffmpeg python3-pip
pip install -r requirements.txt
./run.sh            # Windows: python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

افتح `http://localhost:8000`. من الآيفون على نفس شبكة الواي فاي افتح `http://<عنوان-IP-للكمبيوتر>:8000`.
لحماية النظام بكلمة مرور: `STUDIO_PASSWORD=كلمة-سر ./run.sh` (اسم المستخدم أي شيء).
مكان حفظ الملفات: مجلد `data/` (أو `STUDIO_DATA_DIR`). الأصول في `data/originals` للقراءة فقط ولا تُعدَّل أبدًا؛ النتائج في `data/outputs/<job>`.

## حدود معروفة (بصراحة)

* **لم يُختبر على صور/فيديوهات عقارات حقيقية من البصمة** — بيئة البناء لا تصل للإنترنت. استُخدمت صور فوتوغرافية حقيقية عامة (من مكتبة scikit-image) وصورة واجهة مبنى مولّدة بميلان معروف وفيديوهات مولّدة منها.
* فيديو HDR من الآيفون اختُبر على ملف **محاكى** فقط؛ الألوان على ملف حقيقي تحتاج اختبارًا.
* إزالة العناصر كلاسيكية (OpenCV): ممتازة للعناصر الصغيرة، ضعيفة للعناصر الكبيرة. الحل الأفضل نموذج LaMa (مجاني، يحتاج GPU).
* "التحليل الذكي" قياسات حاسوبية وقواعد مدروسة، وليس نموذج تعلم عميق.
* الموسيقى: لا توجد مكتبة موسيقى؛ يرفع المستخدم ملفه المرخّص (ملف الاختبار مولّد صناعيًا).
* لا يوجد حذف ملفات من الواجهة، ولا حسابات مستخدمين متعددة (كلمة مرور واحدة اختيارية).
* المعالجة على CPU: تصدير 1080p لفيديو 16 ثانية مع تثبيت وانتقالات ≈ 85 ثانية على 4 أنوية.
* الواجهة JavaScript بدون React (لا تحتاج بناء)؛ يمكن نقلها إلى React لاحقًا.
